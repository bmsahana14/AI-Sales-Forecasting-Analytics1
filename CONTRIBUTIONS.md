# 🤝 Contributing to ForecastIQ

First off, thank you for considering contributing to **ForecastIQ**! It's people like you who make this tool better for everyone.

## 🚀 Getting Started

1.  **Fork** the repository and clone it locally.
2.  Install the **Backend** dependencies:
    ```bash
    cd backend
    pip install -r requirements.txt
    ```
3.  Install the **Frontend** dependencies:
    ```bash
    cd frontend
    npm install
    ```
4.  Set up your `.env` file with a valid `GEMINI_API_KEY`.

## 🛠️ Contribution Workflow

### 1. Feature Requests & Bugs
Please open an **Issue** before starting major work. This allows the team (Lead: **Sahana B M**) to provide feedback and ensure alignment with the project roadmap.

### 2. Pull Requests
- Create a new branch: `git checkout -b feature/your-feature-name`.
- Ensure your code follows the existing **Clean Code** patterns.
- Keep the "Neural Stealth" UI aesthetics consistent.
- Submit your PR with a clear description of what changed.

## 🎨 UI Guidelines
- Use **Tailwind CSS** for styling (avoid inline styles).
- Follow the **Glassmorphism** design pattern.
- Ensure all charts maintain high accessibility for business users.

## 📜 Code of Conduct
- Be respectful and professional in all interactions.
- Provide constructive feedback during code reviews.
